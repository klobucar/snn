# Iowa map evidence contract

This package is an offline research inventory. Open [index.html](index.html) directly; it uses local HTML, CSS and images with no JavaScript, CDN, map tiles or network dependency. The first 41 cards and all 99 county rows preserve accepted turnout order. Each county page supplies previews, actual original downloads, partial/archive/source-conflict labels and historical source-scope counts.

The accepted input is `../data/turnout/priority-set.json`, exactly 9,106,895 bytes, SHA-256 `579b22b8d4f35f12d085ef8402a1bcab14e135a1577daf3ddc4f7d3f66460822`. The 369 exact ordered `IA:FIPS` key bytes hash to `e015514b8718b35e9599389cddde2451e5cd598115ef4d6468016a7858271f95`. County FIPS are the accepted Census identities, never invented from a worksheet, shapefile record position or vendor array index. County Page is retained as 19145.

`manifest.json` classifies every acquisition record independently from HTTP success. `manifest.csv` and `inventory/counties.json` retain all 99 counties. County/city filename and municipality associations are navigation aids only: they neither assign a source feature a county ID nor establish reporting-unit equivalence. Cross-county city files retain their original full extent without clipping, division or vote allocation.

`source-manifest.json` and `raw/*.meta.json` preserve requested/final URLs, parent authority, UTC, status, response and redirect headers, decoded entity SHA-256/bytes and stored SHA-256/bytes. Transport content decoding is recorded. HTTP200 HTML viewers, JSON permission errors, unrelated reports and old maps are not accepted as current precinct geometry. Empty403 responses remain failed evidence. `storage-reuse.json` documents exact entity-equal payload reuse; independent request metadata remains distinct. `peer-dependencies.json` pins every used read-only peer extract/original individually; a mutable whole peer ledger is not represented as a final pin. `read-only-pins.json` pins final turnout/coordinator inputs and both final first-wave asset manifests.

The two large Polk original ZIP entities are **exact ordered byte splits**, not independent ZIPs. Every stored part is below 40,000,000 bytes. Use `python3 maps/reconstruct.py polk-all-precincts-dsm-wdm /tmp/polk-dsm-wdm.zip` or the `polk-all-precincts-other` source key from the Iowa directory. The script verifies each part and the joined exact original SHA-256, writes outside the package and refuses overwrites. Joined objects must not be stored here. No original is truncated, resampled or silently simplified.

`geometry-audit.json` and `audit/*.json` enumerate all successfully acquired native ZIPs/layers, all ZIP members with CRC32/bytes/SHA-256, SHP native record-header numbers, SHX/DBF record counts, full field definitions and encoding, native extent, WKT, authority/axis/units and feature checks. These are **static complete archives**: advertised service counts, pagination, transfer-limit flags and pre/post service IDs are not applicable. Every record position is explicitly an ordinal, not a new native precinct ID. Original ID/name/district fields remain literal.

`native/*.json.gz` retain every decoded attribute, original point/part sequence, shape type and separate Z/M arrays; original ZIP bytes remain authoritative for raw DBF padding, deleted records, numeric widths, projection text and unused members. Shapefiles support linear vertices, not true curves; curve support and actual return status are explicitly false. PolygonZ/M support must not be confused with values actually returned. No geometry precision reduction, dissolve, repair, snapping, generalization or allocation is performed. The independent validator rereads every original layer and compares all decoded attributes, vertices, parts and Z/M arrays to the derivative.

GIS validity uses the documented pyshp ring interpretation and Shapely. Native ring orientation is separately recorded. An orphan or reversed ring can be interpreted as an exterior for diagnostic geometry only; no native ring is rewritten. Invalid/self-intersecting/empty/nonfinite features are retained. Pairwise overlap operations skip invalid features explicitly. For a native projected CRS, native intersection area and its native squared units are recorded. Native angular coordinates receive no physical square-degree area claim. The separately declared EPSG:5070 equal-area derivative records square metres; it is not called native area. Positive numerical overlaps, including tiny residuals, remain unfiltered. Raster previews draw every original ring after an always-XY projection to EPSG:5070, fit to pixels; they are display derivatives rather than authoritative area or topology products.

`pdf-audit.json` and `pdf-audit/*.json` retain original PDF/member SHA-256/bytes, all page counts, page dimensions/rotations, PDF metadata and compressed per-page extracted text. `contacts/` contains actual page rasterizations for every audited map/document page; `previews/` contains full-vertex geometry plots and 1800-pixel first-page renderings. PDF original bytes and full-resolution pages are in the original PDFs or original ZIP members. No browser/parser screenshot substitutes for an original PDF. Incidental statistical/results PDFs are explicitly excluded from map coverage and the map rendering totals. Old maps and polling-site buffer maps remain separately labeled reference evidence.

`inventory/constituent-diagnostics.json.gz` contains exactly 13,558 objects in original county/year/context/list order. Each `original_constituent` is the complete exact accepted input object, including blank keys, duplicate labels, source row/sheet/XML paths, clocks and source flags. All 99 native county rosters are conserved separately. Diagnostic statuses are `administrative-no-polygon`, `ambiguous`, `unknown` or `missinggeometry`; the schema also reserves `matched` and `sourceconflict` for documentary evidence. Literal equality only creates ambiguous review candidates, even when there is a single candidate. `approved_polygon_matches` is empty and `vote_allocation` is null for every row. Asset-level wrong-scope districts use `sourceconflict` dispositions in the manifest. These do not remove or rewrite the historical reporting constituent.

The historical counts remain separate: 2024 candidate1653, turnout-context1651, status1653 and administrative99; 2022 candidate1653/administrative99; 2020 candidate1661/administrative99. Registration-statistics labels are1658/1651/1681 for2024/2022/2020. Lucas retains candidate/status7 versus root turnout5, and root VoterTurnout contest keys are blank. Physical precincts, split/styles, central absentee boards, polling locations, registration labels, administrative county controls and reporting rows are different objects. None supplies a current approved crosswalk by name or count.

Reproduce from the repository root with Python 3, `requests`, `pyshp`, `shapely`, `pyproj`, `Pillow` and `PyMuPDF` installed outside this package, using `PYTHONDONTWRITEBYTECODE=1`. No dependency or cache directory belongs here:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/iowa/maps/acquire.py
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/iowa/maps/local_acquire.py
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/iowa/maps/follow_wrappers.py
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/iowa/maps/deduplicate.py
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/iowa/maps/audit.py
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/iowa/maps/render_pdfs.py
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/iowa/maps/build.py
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/iowa/maps/report.py
PYTHONDONTWRITEBYTECODE=1 python3 senate/2026/iowa/maps/validate.py
```

Acquisition reuses pinned responses. County discovery reads the peer's actual recorded links; the retained discovery list is the frozen record of this run. A future peer discovery change can introduce new evidence and must not be silently treated as the same acquisition. The deterministic audit/build/render/report/validation stages are fully offline. `validation.json` reports retained source defects separately from check failures. `asset-hashes.json` hashes owned assets while excluding itself and validation output to avoid circular hashes; the validator checks their content directly. No Git, collector, calibrated forecast or publication action is part of these scripts.
