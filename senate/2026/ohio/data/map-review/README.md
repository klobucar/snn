# Coordinator map-source follow-up

This directory retains 15 bounded public requests with original bytes, status, headers, retrieval UTC and hashes in [manifest.json](manifest.json). Generic `.html.gz` filenames describe lossless capture storage; their actual payloads include JSON, ZIP and PNG. Run `python3 senate/2026/ohio/data/map-review/audit.py` offline (standard library only). The map worker's separate audit covers its copied usable asset and complete package.

Richland's [official county GIS downloads](https://www.richlandcountyoh.gov/departments/auditor/CamaData) link the public shapefile folder. Downloaded GeopoliticalArea contains 36 city/township/county records; CountyDistrict contains eight wards/annexes. Neither is a complete voting-precinct layer. The county service catalog and published layer were also inspected. These alternatives do **not** repair the missing Richland precinct download. The official BOE 166-page PDF was viewable through research-browser text; the screenshot operation supplied only a render reference. No original or rendered asset was obtained, and the empty native-browser inventory supplied no fallback. [Browser observation](browser-access.json) records the limitation.

Tuscarawas's official `BOE_Precints` MapServer returns attributes without geometry even for a minimal one-feature request with `returnGeometry=true`. Its **actual MapServer export works**: [retained PNG](tuscarawas-official-render.png), 2000×2600, 124,878 bytes, SHA-256 `c08224550273054f43636f6fe4bbd1fd72bf84c4ddab0f5802af808049ab33e8`. The [exact request parameters](tuscarawas-render-request.json) preserve the source extent and native EPSG:3734. The image was visually inspected: colored precinct polygons and labels are visible, with dense-label limitations. It is an official server-rendered raster, not recovered vector geometry or evidence of November boundary approval. The maps worker copied the exact PNG and provenance into its own index and manifests.

Historical Tuscarawas PDF acquisition is separately documented by the worker: 16 complete files succeeded from 73 cataloged URLs; 57 connections were refused. That partial historical packet and this raster must not be described as 73 downloaded PDFs or complete current vector coverage. Richland remains Census-reference-only in the usable map index.
